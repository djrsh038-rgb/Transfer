# 설비 HMI 다국어 번역기

자동화 설비의 HMI·조작 패널에 들어가는 문구를 **한국어 · 영어 · 베트남어 · 중국어(간체)** 사이에서 자유롭게 번역하고, 언어별 시트로 나뉜 엑셀 파일로 내려받는 웹페이지입니다.

원본 언어를 고르면 나머지 3개 언어로 동시에 번역됩니다. 한국어 출발뿐 아니라 **영어 → 나머지 3개**, **베트남어 → 나머지 3개**, **중국어 → 나머지 3개** 모두 가능합니다.

API 키나 로그인, 토큰 비용이 필요 없어서 링크만 공유하면 누구나 바로 쓸 수 있습니다.

현재 버전: **v2026.09.17-8** (페이지 맨 아래에 표시됩니다)

---

## 배포 방법 (GitHub Pages)

1. GitHub에서 새 저장소(Repository)를 **Public**으로 만듭니다.
2. 저장소 메인 화면에서 `Add file` → `Upload files`를 눌러 `index.html`을 루트에 업로드하고 `Commit changes`를 클릭합니다.
3. 저장소 상단 `Settings` 탭 → 왼쪽 메뉴 `Pages`로 이동합니다.
4. `Build and deployment`의 `Branch`를 `main`(또는 `master`) / `/ (root)`로 지정하고 `Save`를 누릅니다.
5. 1~2분 후 같은 화면 상단에 `https://<사용자이름>.github.io/<저장소이름>/` 주소가 표시됩니다.
6. 이 주소를 공유하면 누구나 로그인 없이 사용할 수 있습니다.

### 파일을 교체했는데 화면이 그대로일 때

브라우저 캐시 때문입니다. 사이트에서 `Ctrl + Shift + R`(Mac은 `Cmd + Shift + R`)로 강제 새로고침한 뒤, 페이지 맨 아래 버전 번호가 올라갔는지 확인하세요.

## 사용 방법

1. **원본 언어 선택** — 한국어 / English / Tiếng Việt / 简体中文 중 입력할 언어를 고릅니다. 나머지 3개 언어로 번역됩니다.
2. **언어별 최대 글자수 입력** — 번역될 3개 언어마다 다르게 지정할 수 있고, 비워두면 제한 없이 번역합니다.
3. **문구 입력** — 엑셀에서 셀을 여러 개 복사해 입력칸에 붙여넣으면 자동으로 행이 나뉩니다.
4. **자동 번역** — 입력을 멈추면 약 0.9초 후 자동으로 번역이 갱신됩니다. `지금 바로 번역` 버튼으로 즉시 실행할 수도 있습니다.
5. **엑셀 다운로드** — 원본 언어 시트 + 번역 언어 3개 시트로 나뉜 `.xlsx` 파일이 저장됩니다. 각 번역 시트에는 원문, 번역문, 목표 글자수, 실제 글자수가 함께 들어갑니다.

원본 언어를 바꾸면 글자수 입력칸과 결과 표의 열 구성도 자동으로 바뀝니다.

## 주요 기능

### 4개 언어 양방향 용어집

자동화 설비 용어 188개가 4개 언어로 한 줄씩 묶여 있어, 어느 언어에서 출발하든 서로 찾아갑니다. 일반 기계번역이 "티치", "부저" 같은 설비 용어를 엉뚱하게 번역하는 것을 막습니다.

| 한국어 | English | Tiếng Việt | 简体中文 |
|---|---|---|---|
| 수동 | Manual | Thủ công | 手动 |
| 티치 | Teach | Dạy máy | 示教 |
| 비상정지 | Emergency Stop | Dừng khẩn cấp | 急停 |
| 부저 | Buzzer | Còi | 蜂鸣器 |
| 양품 / 불량 | OK / NG | OK / NG | 良品 / 不良 |

`Manual → 수동`, `手动 → Thủ công`, `Thủ công → 手动` 처럼 방향에 관계없이 동작합니다.


### 중국어(간체) 현지 표기 적용

중국어 용어는 중국 본토 공장·HMI에서 실제로 쓰는 표기로 맞췄습니다. 대만식·일본식 한자어는 쓰지 않습니다.

| 한국어 | 잘못 쓰기 쉬운 표기 | 현지 표기 |
|---|---|---|
| 모터 | 马达 (구어·대만식) | **电机** |
| 척 | 夹盘 | **卡盘** |
| 이력 | 履历 (일본식) | **历史记录** |
| 사이클타임 | 循环时间 | **节拍时间** |
| 등록 | 登录 (→ '로그인' 뜻) | **登记** |
| 툴 | 刀具 (절삭공구 한정) | **工具** |
| 밸브 | 阀 | **阀门** |
| 게이지 | 量规 | **仪表** |
| 컨베이어 | 输送带 | **输送线** |
| 다음 / 이전 | 下一个 / 上一个 | **下一步 / 上一步** |

이미 현지 표준인 표기는 그대로 유지했습니다.
`비상정지=急停`, `원점복귀=回原点`, `지그=治具`, `점검=点检`, `양품/불량=良品/不良`, `주화면=主画面`, `운전중=运行中`

설비 현장에서 자주 쓰는 용어도 보강했습니다.
`安全门(안전문), 工序(공정), 设备(설비), 稼动率(가동률), 停机(비가동), 操作员(작업자), 管理员(관리자), 模具(금형), 判定(판정), 返工(재작업), 报废(폐기), 润滑(윤활), 冷却(냉각), 清洗(세정), 上限/下限, 公差(공차)`

### 짧은 HMI 라벨 형태로 번역

문장이 아니라 화면 라벨·버튼용 짧은 명사구로 번역합니다.

- 자동운전 → `Auto Run` (Automatic Operation 아님)
- 자동모드 → `Auto Mode` / 운전모드 → `Run Mode`
- 센서감지 → `Sensor Detect` (Sensor Detection 아님)
- 실린더전진 → `Cylinder Fwd` / 도어열림 → `Door Open`

동작·상태 단어는 다음으로 통일됩니다.
`정지=Stop, 기동=Start, 운전=Run, 감지=Detect, 완료=Done, 대기=Standby, 확인=Check, 저장=Save, 삭제=Del, 전진=Fwd, 후진=Rev, 상승=Up, 하강=Down, 정회전=CW, 역회전=CCW, 클램프=Clamp, 해제=Release, 초기화=Reset`

### 용어집에 없는 복합어 자동 조합

밸브, 모터, 펌프, 로봇, 그리퍼, 비전, 제품, 트레이 등 설비 명사가 등록되어 있어 사전에 없는 조합도 만들어냅니다. 이 기능도 4개 언어 모두에서 작동합니다.

- 밸브감지 → `Valve Detect` / `阀检测`
- 펌프기동 → `Pump Start` / `泵启动`
- `Valve Detect` → `阀检测` (영어에서 출발해도 동일)

### 글자수 제한 시 약어 자동 적용

제한을 넘으면 잘라내기 전에 먼저 표준 약어로 바꿉니다.

- `Temperature Setting Maximum` (15자) → `Temp Set Max`
- `Emergency Stop Button` (10자) → `E-Stop Btn`
- `Maintenance History` (12자) → `Maint Hist`
- `Present Value` (6자) → `PV`

약어로도 부족하면 관사·전치사를 생략하고, 마지막 수단으로만 `…`을 붙여 잘라냅니다.

### 셀 내부 줄바꿈 유지

엑셀에서 한 셀 안에 `Alt + Enter`로 줄을 나눈 문구는 줄 구조가 그대로 유지됩니다. 각 줄을 따로 번역해서 같은 위치에 줄바꿈을 다시 넣고, 글자수 제한도 줄 단위로 적용합니다.

```
전체 도어          All Doors
닫힘        →      Closed
```

엑셀 다운로드 시에도 자동 줄바꿈 속성이 적용되어 두 줄로 보입니다.

### 첫 글자 대문자

모든 번역 결과의 첫 글자를 대문자로 맞춥니다. 줄바꿈이 있으면 각 줄마다 적용되며, 베트남어 특수문자(`đóng` → `Đóng`)도 처리합니다. 중국어는 대소문자 개념이 없어 그대로 유지됩니다.

## 제한 사항

- 번역 엔진은 무료 공개 API인 **MyMemory Translated API**를 사용합니다. 익명 기준 하루 약 5,000단어 제한이 있습니다.
  - 한도를 늘리려면 `index.html`의 `translateOne` 함수 안 요청 URL 끝에 `&de=본인이메일@example.com`을 추가하세요.
- 용어집에 없고 조합도 안 되는 문구는 일반 기계번역 결과가 나오므로, AI 번역만큼 자연스럽지 않을 수 있습니다.
- 글자수 초과 시 AI처럼 의미를 살려 재작성하지는 못하고, 약어 치환 → 불필요어 제거 → 잘라내기 순서로 처리합니다.

`index.html` 안의 `TERMS` 배열에 `[한국어, 영어, 베트남어, 중국어]` 순서로 한 줄만 추가하면 4개 언어 모든 방향에 동시에 반영됩니다.

```javascript
const TERMS = [
  ['수동','Manual','Thủ công','手动'],
  ['배출','Discharge','Xả','排出'],   // <- 이렇게 추가
];
```
